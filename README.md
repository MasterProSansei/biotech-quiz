# Биотехнология — интеллектуальная битва

Адаптивная командная викторина в формате «Своя игра». В проекте одна статическая страница без сборщика, регистрации, платных API или внешних игровых сервисов.

## Запуск на компьютере

Откройте `index.html` в современном браузере. Для локального HTTP-просмотра в папке проекта выполните:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на Render Static Site

1. Загрузите `index.html` и `README.md` в GitHub-репозиторий.
2. В Render выберите **New → Static Site** и подключите этот репозиторий.
3. Укажите команду сборки `echo "Static site ready"` и папку публикации `.`.
4. Нажмите **Create Static Site**. Render выдаст публичный HTTPS-адрес вида `https://имя-сайта.onrender.com`.

Игра рассчитана на один общий экран ведущего: названия команд и ход игры хранятся в `localStorage` браузера. Для сохранения счёта на нескольких устройствах сервер не используется.

## Возможности

- 5 категорий и 25 вопросов со стоимостью от 100 до 500 баллов.
- От 2 до 4 команд, редактирование названий во время игры.
- Таймер на 20 секунд с паузой; по истечении времени ведущий может открыть ответ.
- Автоматическое начисление баллов за верный ответ; неверный ответ без штрафа передаёт ход.
- Сохранение счёта, выбранных вопросов и текущего вопроса при перезагрузке страницы.
- Финальная таблица, победитель и перезапуск партии.
