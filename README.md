# Биотехнология — интеллектуальная битва

Адаптивная браузерная викторина в формате «Своя игра». Игра рассчитана на одну команду, не требует регистрации и работает без установки приложений.

## Запуск

Откройте `index.html` в современном браузере или запустите локальный HTTP-сервер:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Онлайн-версия

Игра опубликована на GitHub Pages: <https://masterprosansei.github.io/biotech-quiz/>.

## Как играть

1. Нажмите «Начать игру», задайте название единственной команды и задайте код ведущего длиной от 5 символов. Не сообщайте его игрокам.
2. После старта код разблокирует управление на всю партию. Чтобы закрыть управление, нажмите «Заблокировать».
3. Выберите категорию и стоимость вопроса.
4. Обсудите ответ за 20 секунд. Таймер можно приостановить.
5. Нажмите «Показать ответ», затем отметьте, верен ли ответ команды.
6. За верный ответ очки начисляются автоматически. Использованный вопрос повторно выбрать нельзя.
7. После всех 25 вопросов команда побеждает, если набрала не меньше 4500 баллов. Максимум за игру — 7500.

## Возможности

- 5 категорий, 25 вопросов, стоимость от 100 до 500 баллов.
- Один общий счёт и редактирование названия команды.
- Однократный вход ведущего на всю партию и кнопка блокировки управления.
- Таймер на 20 секунд с паузой.
- Автосохранение счёта, открытого вопроса и прогресса в браузере.
- Итоговый экран, возврат к полю и перезапуск игры.
- Цель для одной команды: 4500 из 7500 баллов; на финише показывается победа или сколько очков не хватило.
- Во время игры на поле и экране вопроса постоянно видны цель и текущий прогресс команды.
- При первом достижении цели появляется поздравление; ведущий закрывает его кнопкой «Продолжить игру».

Состояние хранится локально в браузере ведущего, поэтому для одной партии используйте одно устройство. Код ведущего защищает игровые кнопки от случайных нажатий; статический сайт не может скрыть ответы от пользователя, который умеет читать исходный код страницы.
